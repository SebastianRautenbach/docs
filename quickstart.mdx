Welcome to WizardMachine! This quickstart will guide you through creating your first script and running it in your project.

By the end of this guide, you will have created a script asset, opened it in your preferred IDE, and started writing your own behaviour.

## Prerequisites

Before you begin, make sure you have:

* **WizardMachine** installed from the Microsoft Store.
* **Visual Studio Code** installed as your preferred IDE.
* The **WIZMEXT** VS Code extension installed for syntax highlighting and code completion.

## Get started

<Steps>
  <Step title="Create a script">
    Open the **Content Browser** in WizardMachine and create a new **Script Asset**.
  </Step>

  <Step title="Open the script">
    Open the script asset in your preferred native IDE, such as Visual Studio Code.
  </Step>

  <Step title="Write your behaviour">
    Start writing your gameplay behaviour using the WizardMachine scripting system.
  </Step>
</Steps>
