WizardMachine is a fully 3D game engine for Windows, built around forward clustered rendering and a custom entity component system (ECS). It's for developers who want to build 3D games in C++ with rendering, animation, AI, and UI in one engine.

## What's included

- **Forward clustered rendering** with a full post-processing pipeline
- **Custom ECS architecture** that lets you attach a component of any class to any entity
- **C++ scripting** for gameplay logic
- **Asset management** for your project's content
- **Skeletal animation** with full support for animated characters
- **Behavior-tree AI** for driving non-player characters
- **Built-in UI system** with text rendering
- **Native Windows support**
